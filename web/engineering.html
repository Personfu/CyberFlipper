▸ DEF CON 34 BADGE / SAO TRACK

SAO-ready content without pretending to be official.

The site now points directly to the official DEF CON 34 SAO spec sheet and frames it as a reference for educational badge add-on planning. The public page focuses on safe engineering outputs: pinout checklist, power budget, mechanical fit, connector orientation, art layer notes, and bring-up logs.

OFFICIAL SPEC PDF
POWER
Document voltage assumptions, current draw, LED budget, and brownout behavior before plugging into a badge.
HEADER
Record connector orientation, pin labels, keyed markings, silkscreen text, and a photo of the assembled add-on.
MECHANICAL
Check board outline, mounting holes, enclosure clearance, cable relief, and pocket-safe edges.
FIRMWARE
Ship a boring first firmware: blink, identify board, print version, log sensor values, and fail safely.
BOM
List parts, alternates, vendor links, quantities, footprints, and substitution risks.
BRING-UP
Use continuity, power-only smoke test, serial log, sensor test, enclosure fit, then public build photos.

Flipper GPIO Practice Shield

A low-risk breakout with labeled pins, resistor-protected LEDs, buzzer, button, and sensor header for teaching GPIO safety without improvising wires in the field.

  • Output: schematic, continuity checklist, photos

  • Story: engineering proof for FLLC client trust

arduino_sensor_serial.ino
const int sensorPin = A0;

void setup() {
  Serial.begin(9600);
  Serial.println("FLLC sensor demo: local bench telemetry");
}

void loop() {
  int reading = analogRead(sensorPin);
  Serial.print("raw=");
  Serial.println(reading);
  delay(1000);
}
