## CyberFlipper Daily Field Pack — 2026-06-19

This release adds a safe SD-card field pack for authorized CyberFlipper research. It includes daily research notes, CISA KEV triage templates, upstream compatibility tracking, device-readable field cards, harmless BadUSB training scripts, protocol review sheets, and visual assets.

Install through qFlipper by copying these folders to the SD-card root:

```text
badusb/CyberFlipper_Lab/
infrared/CyberFlipper_Notes/
nfc/CyberFlipper_Notes/
subghz/CyberFlipper_Notes/
lfrfid/CyberFlipper_Notes/
apps_data/cyberflipper/
assets/cyberflipper/
docs/daily/
```

The BadUSB files are documentation demos only. They type local checklists or banners for lab notes and do not modify the host beyond normal text entry.
