# CyberFlipper Member Lab Roadmap

This roadmap keeps the CyberFlipper public site useful while creating a clean FLLC membership path.

## Content split

| Tier | Share | Role |
|---|---:|---|
| Free | 50% | Public-safe primers, hardware diagrams, defensive checklists, visible audit scripts |
| Basic | 15% | Report templates, lab answer keys, printable field cards, workshop worksheets |
| Premium | 35% | Guided simulations, richer visual workbenches, member-only lab packs, instructor notes |

## Free lanes

- Flipper SD hygiene and backup workflow.
- IR remote baseline with owned consumer devices.
- NFC tag anatomy using owned NTAG test tags.
- Proxmark notes focused on protocol literacy and defensive design.
- GPIO bring-up safety, voltage checks, and smoke-test logs.
- Badgelife/SAO planning, soldering practice, and bring-up evidence.
- CVE presence audit scripts that only collect local product/version/patch evidence.

## Basic member lanes

- CyberFlipper report-writing kit: scope, evidence, impact, fix, retest.
- Payload card review rubric: visibility, reversibility, logging, authorization.
- RF/NFC field worksheet: owned gear, frequency, environment, result, lesson.
- Workshop facilitation pack for classroom or meetup delivery.

## Premium member lanes

- Browser-based RF waterfall simulator using synthetic samples.
- Interactive SVG circuit traces for Flipper/ESP32/CC1101 boards.
- Step-by-step defensive validation labs for sanctioned systems.
- Portfolio-grade hardware build review with BOM, photos, firmware output, and remediation notes.

## Non-negotiable boundary

CyberFlipper can sound aggressive and look like a dangerous neon workbench, but published content must remain owned-lab, classroom, bug-bounty, or contracted-scope only. No credential capture, stealth, persistence, evasion, reverse shells, or unauthorized testing.
