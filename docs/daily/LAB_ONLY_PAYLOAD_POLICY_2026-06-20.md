# Lab-Only Payload Policy — 2026-06-20

CyberFlipper lab payload documentation is limited to visible, local, benign demonstrations.

Allowed examples:

- Type a visible marker into an already-open text editor.
- Type a local test checklist.
- Display a reminder to record scope, owner, date, and device serial number.

Not allowed in repository examples:

- Shell launch or command execution.
- Network access.
- File, browser, clipboard, token, cookie, key, or password access.
- Security-setting modification.
- Persistence or background behavior.
- Destructive behavior.
- Third-party system interaction.
- Physical-access bypass steps.

Review standard:

A lab payload is acceptable only when a reviewer can read it line by line and determine that it performs visible local text entry only.
